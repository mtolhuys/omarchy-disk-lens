# Assets

Planned public-release assets belong here:

- project icon and monochrome bar glyph source;
- marketplace/README hero image;
- synthetic-fixture screenshots for light and dark themes;
- optional short interaction recording.

Assets must contain no real home-directory paths, usernames, mount labels, filenames, or other private metadata. Generated derivatives should be reproducible from committed sources where practical, and third-party assets require documented license/attribution.
